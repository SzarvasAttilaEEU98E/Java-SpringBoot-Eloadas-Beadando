Az alkalmazásról

Ez a böngészőből használható, helyi gépen futó alkalmazás Java 25 és Spring Boot használatával készül. Az MNB SOAP webszolgáltatásából devizaárfolyamokat kérdez le, és Chart.js segítségével jeleníti meg azokat.

Az OANDA API-n keresztül Forex számlainformációkat, árfolyamokat és kereskedési műveleteket fog kezelni. A funkciók fejlesztése folyamatban van.
